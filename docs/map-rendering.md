# 全屏世界地图

桌面参考画面的有效游戏区为 2560 × 1440。首页按其坐标绘制新闻、日期、倍速、缩放轨和底部概况。地形与 HUD 独立；相机运动只改变地图内容。角标、面板轮廓、图标和事件窗可以分别编辑。实机教程用于观察镜头与云带外观，原作采用的数据源和算法未公开验证。

## 地形与镜头

| 参数 | 实现 |
| --- | --- |
| 地表 | NASA 十一月卫星合成和 Natural Earth I 以经纬度对齐。4096 × 2048 地表纹理包含陆地和海底色阶。 |
| 网格 | Mapzen Terrarium 第 3 级全球高程；720 × 360 个四边形，521 千字节的有符号 16 位米制数据。顶点处正海拔每千米抬高 0.55 个场景单位。海面保持零高程，海底深度进入底色。 |
| 投影 | 经度对应场景 X，纬度乘 1.18 对应场景 Y。左右沿日期变更线重复。每个国家的 SVG 路径同时用于普通描边、选中蒙版和命中测试。 |
| 镜头 | 36° 垂直视场，缩放行程为 0–1。全球总览按可用宽高自动取景。至 0.32 时平滑过渡到区域镜头的指数缩放曲线。俯仰从 0° 连续过渡到 56°。竖屏触控设备顺时针旋转游戏区 90°，竖向桌面窗口按自身宽高取景。 |
| 交互 | 滚轮、缩放轨、拖动、双指、键盘、全球与欧洲预设。点击穿过云层、采样地表高程后求国家轮廓命中。命中六个市场的任一地块都会高亮所属大洲，地区目录可直接切换大洲。 |

最远档以本初子午线和赤道为地图中心。相机按实际画布的可用宽高、360 × 212.4 的地形范围及最高地形的透视余量计算距离。上下边距分别预留新闻和地区概况的位置，左右留出缩放轨的宽度。窗口尺寸变化时，三维和二维视图使用相同取景。HUD 按宽、高相对参考尺寸的较小缩放因子等比绘制；角落控件贴边，地区概况锚定底边中央。

游戏的「中国」选区使用一个多面 SVG 路径，包含大陆、台湾以及 Natural Earth 1:10m 所收录的 21 个南沙岛屿轮廓。小岛保留五位小数的经纬度。群岛标记可在全球尺度点选，标记之外按实际路径拾取，岛间水域可单独查看。该归组用于游戏显示。[Natural Earth 1:10m 图层](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-details/)

## 十一月环境场

大气采用 NCEP/NCAR Reanalysis 1 的 1991–2020 年十一月气候态。取 850 hPa 的东西风、南北风和相对湿度，原网格 2.5°。程序在湿润区提高云密度，以风矢量向上游回溯、移动并形变云纹。双相位交叉淡化消除纹理重新播种时的跳变。云层位于地形上方，云影用同一密度场偏移采样。云的具体轮廓为程序生成，不能用于还原某一天的天气。[压力层资料](https://psl.noaa.gov/data/gridded/data.ncep.reanalysis.html)

表层洋流来自 NOAA Global Drifter Program v3.10 十一月多年平均速度场。原网格 0.25°，每四个格点取样一次。1850 条短迹线在速度场中积分；使用纬度余弦把东向米每秒换算为经度变化。地表陆地掩码、缺测值及日期变更线切断轨迹。极区的缺测格保留为空。常速下云场时间放大 4800 倍、洋流放大 30000 倍，保留各图层内部的速度差异。地区档案显示原始量纲的速度与流向角，正北为 0°。[漂流浮标数据和使用许可](https://erddap.aoml.noaa.gov/gdp/erddap/griddap/drifter_monthlymeans.html)

环境动画以浏览器时钟运行，可暂停、倍速或独立隐藏。系统开启“减少动态效果”时显示静止环境并即时定位。日期、新闻和疾病数值是固定的界面状态，交通路线只作示意。

## 数据制作与文件

`scripts/prepare_map.py` 使用 Python、NumPy 和 Pillow。已生成文件随源码提交，正常开发、构建及玩家访问均读取同源静态文件。「世界 → 地图数据与署名」列出原始影像、地理数据、照片和许可。

```sh
python scripts/prepare_map.py PATH_TO_DOWNLOAD_CACHE
npm run build
```

- `atlas.ts` 解析 SVG、米制高程和环境场。高程从北向南排列，含经纬度两端点。风及流速四分量从南向北排列，起始格点为 179.875°W、89.875°S；风为厘米每秒，洋流为毫米每秒。缺测哨兵为 −32768。
- `camera.ts` 管理透视矩阵、地理定位、滚轮和触控导航。`MapViewport.tsx` 将交通标志投影到屏幕，并提供 WebGL 不可用时的二维 SVG 地图。
- `TerrainScene.tsx` 装配地形、云层和洋流。`materials.ts` 定义地表、随流移动的水面细纹和云的着色器。`currents.ts` 积分浮标流场并维护短迹线。
- 全屏 SVG 控件位于 `scenes/world/Hud.tsx` 和 `Symbols.tsx`。参考地图的固定数值位于同目录的 `preview.ts`。基辅小窗使用单独授权的真实街景，其他选区显示当地卫星影像。[地图场景](../apps/web/src/scenes/world/WorldScene.tsx) · [完整数据署名](../apps/web/public/map-credits.html)

## 验证记录

生产构建通过四组 tsrs 检查。在 Chromium 软件 WebGL 2 中，全球俯视、43.28° 默认近景及 56° 最大倾角均可到达。1280 × 720 下验证了滚轮、滑杆、拖动和倾斜时的陆海点选。暂停后地图区域相邻帧逐像素一致；单独关闭云层或洋流均有可测的像素变化。测试时地图文件请求全部来自站点自身。

390 × 844 的浏览器触控模拟验证了横向游戏区及双指缩放。禁用 WebGL 时会加载包含 241 个可选地区的 SVG 地图；模拟 WebGL 上下文丢失并恢复后可继续缩放与点选。移动端帧率有待用实际硬件测量。

全球取景另在 2506 × 1910、4:3、16:9、超宽、正方形和桌面竖屏窗口实测。用已知经纬度的机场反算投影边界，确认最远档完整显示 360° 经度与两极，且位于新闻、缩放轨和底部概况之间。二维降级视图也核验了完整范围。大陆、台湾及南沙岛屿命中同一地区，抽查的岛间水面命中海域。
