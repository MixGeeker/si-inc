# 算力快照

游戏里的传播靠算力中心，不靠港口和机场。这份快照把 compute-globe 调研库里已经算好的单站结果，固定成 六个大洲市场能直接读取的数据。内容版本 `data-f9b37f94f0e6d484`，研究截止 **2026-09-20**，评估日 2026-09-25。对局不再回连原调研库，也不随新报道更新。

数据在 [compute.json](../packages/rules/v0.1/world/compute.json)，由 [compute.ts](../packages/rules/v0.1/world/compute.ts) 按现有市场 ID 导出。

## 拿过来的是什么

只用两类已经算完的数：

| 字段 | 含义 | 游戏里可以怎么用 |
| --- | --- | --- |
| `realMw` | 单站装机功率；没有装机记录时用建成功率。单位是 MW | 当前算力。市场合计后换成 `recordedRealShareBps`，10,000 等于这批资料里的全部当前功率 |
| `envMw` | 同一单站的宣称、建成、装机三者取最大 | 资料里出现过的规模包络。它包含已经落地的部分，不是还能再加的未来增量 |
| `lat` / `lon` | 设施坐标，并带 `precision` | 地图上的算力点。`exact_site` 是园区，`city` 只到城市，`country` 不能画成一栋楼 |

另外保留了站点状态、设施类型（自建、托管、主权、公共超算）和电网区域名称。电网区域说明供电背景，例如 PJM、ERCOT、蒙西电网。它不是海缆，也不是互联网交换点。

原库还有 1,746 条事实、1,225 个来源、公司股权拆分、国家政策长文、区域汇总和跨站项目。这些没有复制进来。区域汇总、未定位算力池、跨站项目、发电和并网容量如果再加一遍，会和单站重复。

## 没有拿的部分

compute-globe 没有港口、机场、海缆或通信枢纽。所以这份快照只能支撑「算力中心」这一层。通信设施如果以后要做成另一条传播渠道，需要另找资料，不能从这些坐标推出来。

快照也不是全球普查。没有亮点，只表示这轮调研没有收录可定位的单站。

## 六个大洲市场

单站按机房所在国家的游戏大洲归属统计。亚洲汇总东亚、南亚、东南亚及西亚等地收录的设施。非洲和南美在这批资料中没有收录的单站。

当前功率合计 6,785.2102 MW，来自 221 座单站里的 56 座。份额按万分比显示，舍入余数分给小数部分最大的市场。保加利亚的 0.0102 MW 计入欧洲。

| 市场 | 单站 | 有当前功率 | 当前 MW | 包络 MW | 当前功率份额 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 北美 | 115 | 22 | 3,784.5 | 38,181.7 | 55.77% |
| 南美 | 0 | 0 | 0 | 0 | 0% |
| 欧洲 | 38 | 14 | 305.9102 | 5,113.0102 | 4.51% |
| 亚洲 | 59 | 16 | 2,471.8 | 16,078.7 | 36.43% |
| 非洲 | 0 | 0 | 0 | 0 | 0% |
| 大洋洲 | 9 | 4 | 223 | 1,184 | 3.29% |

北美和亚洲合计占已记录当前功率的 92.20%。非洲和南美使用这份资料做传播模拟时，还需确定缺少设施观测时的基础可及性。
